发布： llm 0.32rc1

LLM 0.32 的这个 RC 版本完成了在 LLM 0.32a0 中开始的工作——它增加了一个 新的模式设计，能更好地捕捉最新模型家族返回的提示和响应的详细信息。

最重要的变化是使用内容可寻址的哈希 ID 来存储消息。这实现了数据库中的去重，并且意味着 LLM 现在可以表示分支对话的消息树。

由于这是一个重大的模式变更（仅新增表，旧数据完全不受影响），因此在升级到 RC 版本前，最好先备份你现有的 logs.db：

llm logs backup logs-backup.db

该 RC 版本还增加了对 gpt-5.6-sol、gpt-5.6-terra 和 gpt-5.6-luna 的支持。
