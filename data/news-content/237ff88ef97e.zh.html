前言

欢迎阅读我们关于在 Espressif 产品上进行嵌入式 Rust 开发的指南。本书旨在帮助您入门，并熟练使用我们的工具和生态系统。在过程中，我们将介绍软件栈的结构，并使用项目生成和工具演示基本工作流程。最后，您将准备好通过我们的参考文档和外部培训资源探索更高级的内容。

本书读者

本书面向对嵌入式开发感兴趣的 Rust 开发者，即使他们没有嵌入式系统的经验。虽然熟悉底层编程概念会有所帮助，但我们会在介绍关键概念时进行说明。如果您想扩展基础知识，可以考虑学习附加的资源。

稳定性和可用性

尽管我们力求稳定，但随着 API 改进、性能提升和新功能引入，用户应预期会有定期更新。根据语义版本控制（SemVer）原则，已稳定的模块不会发生破坏性变更。然而，unstable 功能（如 esp-hal 的部分组件和某些驱动程序）仍在积极开发中，不受 SemVer 保证约束。这意味着使用这些 unstable 组件可能导致项目在执行简单的 cargo update 时失效，类似于使用 Rust 的 nightly 编译器。这种不稳定性在整个 Rust 嵌入式生态系统中普遍存在，该领域仍在快速发展。请预期频繁变更并密切跟踪依赖关系。对于所有主要 crate，我们提供版本间的迁移指南，帮助您保持最新状态。
