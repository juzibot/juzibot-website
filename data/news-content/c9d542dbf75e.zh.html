uv 0.12.0

这次 uv 发布带来了一些有趣的重大变更，特别是 uv init 命令生成的默认项目结构。

uv init 是 uv 中用于创建新项目的快捷命令。在 uv 的上一个版本 0.11.x 中，当你运行 uv init uv-init 时，会生成这样的目录结构。

这是uv 0.12 版本生成的结果。我有一个 GitHub 仓库会自动快照 uv init 的输出，所以你也可以查看完整的差异对比：

现在 uv init 默认会生成一个 src/ 形式的包结构，而不是直接在项目根目录下放置 main.py。它还会在运行 uv build 时，为构建 wheel 和 .tar.gz 分发包文件配置 uv_build 后端。最后，它会设置一个 uv-init 的脚本别名，当你用 uv run uv-init 运行时，它会执行 src/uv_init/__init__.py 里的一个新 main() 函数。

到目前为止，我因为习惯问题，在自己的项目中一直避免使用src 布局。我想是时候切换过来了。

我在想 uv 什么时候才能被认为准备好发布 1.0 版本了呢？
