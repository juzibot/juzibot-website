如果你在 Kindle 更新到过高版本之前，成功 把 Tailscale 装在了越狱的 Kindle 上，那你可就赚大发了，即便这体验还不算完整的 完整版 Tailscale。但好事多磨（或者说，多逛逛 GitHub 就能找到）。

开源开发者们优化了 Tailscale 在你拥有的最弱性能电脑之一上的体验。如果你的 Kindle 已经越狱，Mitanshu Sukhwani 更新版的 Tailscale 实现方案带来了几个新功能：

  • 默认启用 Tailscale SSH，这样你就不必启用 USB 网络的 SSH，也不用使用它那过于明显的默认用户名/密码
  • 新增代理模式，让 KOReader 这类应用可以访问你 tailnet 上的 其他节点，比如 Calibre/OPDS 或 Wallabag 服务器
  • 支持完整的 TUN 模式，在某些 Kindle 型号上，能让 Tailscale 网络在设备层面正常工作

我们来逐一看看这些功能如何设置。和之前一样，这是社区开发的非官方设备代码，请保持耐心。

Kindle 上的 Tailscale，现在支持代理了

上次我们写 Kindle 上的 Tailscale 时，客户端功能很基础，但能用。Kindle 会出现在你的 tailnet 上，网页管理控制台里还会显示一个绿点。你可以通过 Tailscale IP 地址访问 Kindle。甚至还能通过 Tailscale SSH 连接到 Kindle，这对进一步折腾很方便。

但事实证明，“可通过 Tailscale 访问”和“将所有传入和传出流量通过你的 tailnet 路由”并不是一回事。越狱 Kindle 上的 Tailscale 通常被迫在 用户空间模式下运行，这意味着它无法使用设备自身的网络路由层，也就是所谓的 TUN 模式。你可以启动 Tailscale，然后启动像 KOReader 这样的应用，但当你尝试连接到另一个 Tailscale 设备（比如你的 Calibre 服务器，地址为 100.x.y.z）时，情况会是这样的：

  • KOReader（或任何应用）询问 Kindle 的根操作系统如何到达 100.x.y.z
  • Kindle 缺少 Tailscale 路由功能，无法到达那个 Tailscale IP 地址
  • KOReader 放弃连接

greywolf1499 对 Kindle KUAL 应用的更新提供了不同的模式来解决这个问题。现在，当你在 Kindle 上尝试访问另一个 Tailscale IP 地址时，流程可以是这样的：

  • 你以代理模式启动 Tailscale
  • 你设置 KOReader 或其他应用的代理设置，连接到 127.0.0.1:1055
  • KOReader 告诉代理它想访问 100.x.y.z
  • Tailscale 的守护进程 tailscaled 在 1055 端口监听，并通过 Tailscale 路由该连接
  • 电子书、文章和其他数据在你的运行着 Tailscale 的 Kindle 和其他 Tailscale 设备之间流动

这个 Tailscale 代理提供了两种模式：SOCKS5 和 HTTP CONNECT，供可能偏好其中一种的应用使用。这为你的联网能力更强的 Kindle 开拓了更多实用功能。

使用代理 Kindle 能做什么

这里有几个大胆的想法，取决于你想深入到什么程度：

  • 如前所述，搭建 Calibre 或 Wallabag 服务器
  • 通过 KOReader 连接 Audiobookshelf
  • 使用 Readest 跨设备追踪阅读进度
  • 将 KOReader 的 RSS 阅读器链接到 自托管的源服务器
  • 在（相当糟糕的）Kindle 浏览器中访问简约的仪表盘和网页
  • 使用蓝牙键盘和 kterm 应用 通过 SSH 连接到 tailnet 设备

最后一点真的实用吗？其实不然。但想到你把最不可能的瘦客户端都加进了“以防万一”的工具箱，是不是有种莫名的温暖？对某些像我一样了解的类型来说：是的。

适用于 KOReader 的 Tailscale 插件（支持 Kobo 和 PocketBook）

如果你除了功能强大的 KOReader 应用外，并不需要其他 Tailscale 功能，可以看看 这个 Tailscale KOReader 插件。它不像基于 KUAL 的应用那样能让你的 Kindle 在 tailnet 上被访问，但它会自动创建代理接口，让你从运行 KOReader 的 Kindle——或是你的 Kobo 设备、PocketBook——访问你的内容服务器。

我自己还没真正试用过这个扩展；我的第 11 代标准 Kindle 目前和它不太兼容。不过它已在“Kindle PW5/PW6、Kobo 和 PocketBook 上测试通过”——很高兴看到 Tailscale 也来到了其他一些 KOReader 友好的设备上。

安装过程不算太复杂，至少如果你已经成功越狱到这一步的话。你只需将插件复制到 KOReader 的插件目录，然后在 KOReader 菜单中触发“安装/更新 Tailscale”，将 一个 Tailscale 密钥 复制到某个目录，接着在 KOReader 菜单中开启 Tailscale。之后，你可以使用 KOReader 的其中一个代理地址进行配置（SOCKS5 用 127.0.0.1:1055，HTTP CONNECT 用 :1056），然后将其他插件需要访问的 Tailscale IP 地址提供给它们。

Victoria Riley Barnett 的仓库提到，该插件与 一个 KOReader 的 SyncThing 插件 配合使用效果很好。就目前而言，KOReader 对于已越狱的 Kindle 来说，就像是它自己的独立操作系统。
