我用 C 语言和 SDL 2 写了一个可移植的 Fasttracker II 克隆版。这里有一张截图。
什么是 Fasttracker II？可以在 Wikipedia 上了解。

注意：如果你的 PC 连接了多个显示器，并且它们的刷新率不同，你可能会遇到一些程序问题！

FT2 克隆版 v2.22 下载：（2026年7月19日 18:36 - GMT +2 - 更新日志）
  • Windows (Windows 7 SP1 及更高版本)
  • Windows 32位 (Windows 7 SP1 及更高版本。仅在确实需要时使用。可能会被误报为病毒！)
  • macOS - Intel 和 Apple silicon (通用版) (OS X 10.11 及更高版本 - 请阅读下方的 Mac 注意事项！)
  • 适用于 amd64/x86_64 的 Linux 软件包（本人不提供支持，也不确定你需要哪个文件）

源代码和更多信息可以在 GitHub 上找到。请阅读 "HOW-TO-COMPILE.txt"。可在 Linux 上编译。

Windows 重要注意事项：
  • 如果 ALT+F4/ALT+F5（复制/粘贴块）不工作，并且你使用的是 NVIDIA GPU，你需要确保
    这些按键绑定在 'GeForce Experience' 中被禁用了（如果已安装）。
macOS/OS X 重要注意事项：
  • 要实际运行程序，你需要右键点击 .app/程序文件，然后选择“打开”。这只需要做一次。 如果你使用的是现代版本的 macOS，在尝试运行程序后，你需要在 系统设置 -> 隐私与安全性 中允许程序运行。
  • FT2 中的许多重要按键绑定被占用了，必须在操作系统中重新映射或移除
  • 要切换全屏模式，请按 ALT+Enter 或 Ctrl+Cmd+F
Linux 重要注意事项：
  • 要让 ALT+F4（复制图案）和 ALT+F5（粘贴图案）生效，你必须在操作系统中将这两个键盘快捷键更改为其他组合。
