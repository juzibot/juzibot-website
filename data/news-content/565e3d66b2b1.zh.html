DeepSeek-V4-Flash 更新​

DeepSeek-V4-Flash API 现已正式发布公开测试版。API 调用方式保持不变 — 只需将模型名称设置为 deepseek-v4-flash 即可使用最新版本。

代理能力显著增强，基准测试结果远超 V4-Pro-Preview：
  • Terminal Bench 2.1: 82.7
  • NL2Repo: 54.2
  • Cybergym: 76.7
  • DeepSWE: 54.4
  • Toolathlon 已验证：70.3
  • Agent Last Exam: 25.2
  • Automation Bench (公开版): 25.1
  • DSBench-FullStack: 68.7
  • DSBench-Hard: 59.6

注 1：在公开基准测试集中的代码代理任务中，官方 DeepSeek-V4-Flash 使用即将发布的 DeepSeek Harness 最小模式作为框架进行测试，设置最大努力级别、topp=0.95 和 temperature=1.0
注 2：DSBench-FullStack 是内部全栈开发测试集，DSBench-Hard 是内部代码代理难题测试集

官方 V4-Flash 原生支持 Responses API 格式，并专门针对 Codex 进行了适配。具体配置请参考 文档。

DeepSeek-V4-Flash-0731 与 DeepSeek-V4-Flash-Preview 保持相同的模型架构和规模，仅进行了重新后训练。

注意：本次更新仅升级了 DeepSeek-V4-Flash API。DeepSeek-V4-Pro API 以及 APP/WEB 模型保持不变。
DeepSeek-V4-Pro 的正式发布将很快推出。

DeepSeek-V4​

DeepSeek API 现已支持 V4-Pro 和 V4-Flash，可通过 OpenAI ChatCompletions 接口和 Anthropic 接口访问。要使用新模型，base_url 保持不变，模型参数应设置为 deepseek-v4-pro 或 deepseek-v4-flash。

两个旧版 API 模型名称 deepseek-chat 和 deepseek-reasoner 将在三个月后（2026-07-24）停用。在此期间，这两个模型名称分别指向 deepseek-v4-flash 的非思考模式和思考模式。

更多详情，请参考 此文档。
