发布： datasette-apps 0.2a0

在使用 Datasette Agent 创建和编辑 Datasette Apps 时，以下改进提升了体验：

  • 新增 app_debug() 工具，允许 Agent 打开一个应用（不可见地）并使用 JavaScript 对其进行测试。#33
  • 新增 app_list() 工具，用于列出用户有权限编辑的应用，以便 Agent 可以编辑它们。#36

app_debug() 工具非常巧妙：它的工作方式是在一个设置了 opacity: 0 和 pointer-events: none 的 iframe 中显示应用（因此它不可见也无法交互），然后在该沙盒化的 iframe 中执行 Agent 提供的 JavaScript。这意味着 Agent 可以对应用进行冒烟测试，甚至可以测量不同元素的尺寸。

这使用了在 datasette-agent 0.4a0 中新增的 context.browser_task() 机制。
