smevals - 一个小型评估套件，用于评估模型、提示词和测试框架

我一直在与 Jesse Vincent 的 Prime Radiant 应用人工智能研究实验室合作，共同构建这个评估框架，以帮助解答关于不同模型能力的问题。

最终成果是 smevals，一个用于在不同模型配置上运行小型评估套件并对结果进行评分的新工具。

这篇博客文章详细介绍了该工具。以下是十秒钟的速览版本：

  1. 让你的编程代理执行 run uvx smevals docs 来学习这个工具（这会输出README 文件）
  2. 然后让它为你构建一个评估套件

一旦你创建了一个评估（它表现为一个包含一些 YAML 文件的目录），你就可以像这样用它来测试模型：

uvx smevals run path-to-eval/ -m gpt-5.5 -m claude-opus-4.6

运行操作与评分操作是分开的 - 你可以使用以下命令对你的运行结果进行评分（针对你定义的检查集）：

uvx smevals grade path-to-eval/

然后你可以运行一个本地网络服务器来探索结果：

uvx smevals serve path-to-eval/

或者运行 smevals build 命令将报告构建为静态 HTML 文件，然后你就可以在任何地方托管它。这是一个示例，展示了我构建的一个用于评估模型写俳句能力的评估套件。

这个项目中耗时最长的部分是为它确定术语！以下是我最终确定的词汇，引自公告：

  • eval 是一系列挑战的集合，旨在回答关于模型的问题，例如，该模型生成 SVG 的能力有多强？
  • 每个 eval 都是一组任务。任务是一个具体的挑战，例如“生成一张鹈鹕骑自行车的 SVG 图片”。
  • 当你运行 eval 时，需要针对一个或多个配置进行。每个配置都指定了要评估的模型，但也可能包含其他要测试的参数，例如不同的系统提示、模型参数或代理工具。
  • 运行记录了使用特定配置执行特定任务时发生的情况。运行器是执行运行的脚本。
  • 当你收集到一个或多个运行结果后，需要评估结果，以了解模型（或配置）的表现如何。这项工作由评分器完成，它会生成一个评分。
  • 每个评分器都会运行一系列检查。这些检查可以很简单，比如检查输出中是否包含特定字符串，或确认输出是否为有效的 XML。它们也可以是更复杂的自定义操作（作为名为检查器的脚本实现），包括使用其他模型来回答关于运行结果的问题。

几年来，我一直在尝试寻找一种我喜欢的评估方法。smevals是我在这个想法上的第三次迭代，我觉得这次的感觉对了。我期待着未来能进一步扩展它，并将其应用于我自己的项目中。
