开源模型

也叫 Open Source Model / 开放权重模型

指模型权重和代码公开，允许任何人免费使用、修改和分发的AI模型。它极大降低了企业应用AI的技术和成本门槛，但也加剧了同质化竞争，促使厂商在服务、场景化和生态上构建壁垒。
